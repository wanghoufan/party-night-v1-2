# Party Night V2｜03 谁最可能

> **核心职责：** 利用全桌外部视角发现关系信号：从普通社交观察逐步升级到 Pair Vote，但群众判断永远不替代当事人的真实选择。

## 执行规则

- 大多数题只“投票 → 公布结果 → 下一题”，不强制得票者追加真心话或大冒险。
- 4档采用 Pair Vote（投一对），结果只产生 Crowd Signal，不等于 MATCH；本玩法不单独提供5档，因为“群众判断”不能替代双方确认。
- 允许全桌起哄“看起来有火花”，禁止系统宣布“你们就是一对”或据此强制身体接触。
