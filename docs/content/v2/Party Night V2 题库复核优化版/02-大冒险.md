# Party Night V2｜02 大冒险

> **核心职责：** 把语言变成行动：通过协作、眼神、距离与双向同意，让两个人真的产生空间和动作上的关系变化。

## 执行规则

- 1–2档以系统指定异性为主；3–4档允许主动选择异性；5档优先给 MATCH 对象。
- 身体接触永远需要双方当场明确同意；任意一方跳过均不追问、不罚酒、不公布是谁拒绝。
- MATCH 只代表双方愿意继续了解，不等于任何身体接触的默认同意。
