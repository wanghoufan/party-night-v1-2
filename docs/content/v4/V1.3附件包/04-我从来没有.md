# Party Night V2｜04 我从来没有

> **核心职责：** 共同经历探测器：发现“原来你也这样”的相似经历，并把有效共同点转成 Shared Signal。

## 执行规则

- 默认流程是“陈述 → 玩家回答 → 系统统计共同点 → 下一题”，不强制追问“是谁/为什么”。
- 标准回答统一为“做过 / 没做过 / 跳过”。只有1～3档中选择“做过”的少数玩家之间，才可形成轻量 Shared Signal；“都没做过”不算共同经历。
- 4档高关系题使用私密回答，默认不产生 Pair Signal；它们只用于控制当前题目的展示与节奏，避免把“今晚对某个人有感觉”错误地配对给另一个同样回答“有”的人。
- 当80%以上玩家都选择“做过”时，该题不计入 Shared Signal，避免大众经历污染。
- 5档只保留终局的秘密对象选择；其结果属于 Personal / Mutual Signal，不属于 Shared Signal。
