# Party Night V2｜05 二选一

> **核心职责：** 恋爱与社交偏好扫描器：用高频、低负担的二选一暴露价值偏好，并计算 Compatibility Signal。

## 执行规则

- 默认每张卡由全桌同时选择 A / B，再统一亮答案；系统可据此计算 Compatibility Signal，但不要求选完后做任何动作。
- 1～3档默认公开；4档是否私密由卡片元数据固定决定，不使用“根据氛围”这种不可执行条件；5档 MATCH 题按题面采用双人或私密回答。
- 同一对异性在多题中答案一致时可增加 Compatibility Signal，但答案相同不等于好感，更不等于 MATCH。
- 当某一选项被80%以上玩家选择时，该题视为“低信息量共识题”，不计入 Compatibility Signal，防止热门答案把所有人虚假算成高兼容。
- 计算相似度时排除跳过和低信息量题；至少共同回答3道有效题后，才允许产生 Compatibility 加权。
- 4档私密题 #41 / #42 与 MATCH 终局 #50 **不进入 Compatibility 累计**；这些答案只服务当前回合，避免把私密关系意愿沉淀成长期兼容数据。
