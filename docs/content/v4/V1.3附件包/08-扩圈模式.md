# Party Night V2｜08 扩圈模式（可选模块）

> 本模块不计入主线 7 类 × 50 = 350 张。默认关闭；只有玩家主动开启“扩圈模式”后才进入候选池。

## 定位

- 作用：把本桌互动短暂扩展到附近愿意参与的人，但不能打断本桌主线关系推进。
- 本模块表格中的 3 / 4 / 5 表示**最低开放度解锁要求**，不是主线的 Relation Stage；扩圈模式不参与5档“双向确认”语义。开放度低于3时完全不可见。
- 硬规则：**先征得同意 / 拒绝无惩罚 / 发起方可跳过 / 不索要联系方式 / 不要求饮酒 / 不进行陌生人身体接触**。
- 任何陌生人拒绝或现场不适合时，立即执行本桌替代版本，不再二次邀请。
- 扩圈结果不计入 MATCH；不进入 Pair Score；最多只记作一次普通 Session Event。
- 40 张扩圈卡的逐卡执行数据见 `10b-扩圈元数据.json`；其中 `fallbackPolicy=switch-to-table-version` 表示陌生人拒绝后立即切回本桌替代版本，不再二次邀请。
