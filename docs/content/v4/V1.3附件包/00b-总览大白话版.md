# Party Night V2｜00 总览与统一规则（V1.3·大白话版）

> **版本提醒：** 以后做 SDD / 开发，只看 V1.3。本包以前的 V1.2、旧 V2 都当历史资料，不能混着用。

## 先记住一句话

**Party Night 不是随机抽题，也不是替人撮合。它是先让所有人都有机会认识，再把真正出现的共同点和好感慢慢放大。**

## 1. 一局游戏应该怎么发展

开场不要猛。先让不同男女组合都说上话、做点轻互动；熟一点以后再出现“我选谁”“大家觉得谁和谁有火花”；等到双方真的秘密互选成功，才给这两个人开放5档内容。

简单说就是：

**先公平认识 → 再发现火花 → 最后只放大真的火花。**

## 2. 1～5档怎么理解

- 1档：注意到你。
- 2档：开始了解你。
- 3档：我开始释放一点“我对你有兴趣”的信号。
- 4档：明显暧昧、公开选择、关系试探。
- 5档：必须两个人都有明确意愿以后才能进入。

玩家开局选5档，只是说“今晚最高愿意玩到5”，**不是第一题就来5档**。

## 3. 整桌只会升温到第4阶段

整桌从 H1 慢慢到 H4。第5档不是“全桌升级”，而是某一对男女单独解锁。

比如 A 和 D 互相选中了，但 B、C 没有，那么只有 A+D 能玩他们的5档题。

## 4. 系统先照顾没怎么玩到的人

前半场优先让不同组合都互动。系统不能总让最外向的两个人反复出场。

什么叫一次有效互动？大白话就是：**系统真的把两个人放进同一道定向题里，而且这道题没有跳过，确实答了或做了。**

H1～H2 至少40%的题应该是这种定向题，而且最多连续两张“全桌一起答”；再往后就要插入一张两人定向互动。

## 5. 系统怎么看“这两个人可能值得再玩一次”

从弱到强大概是：

1. 两个人有共同经历。
2. 两个人很多偏好一样。
3. 全桌都觉得他们有点默契。
4. 其中一个人自己主动选了另一个。
5. 两个人秘密互相选中了——这才叫 MATCH。

前四种都不能当作“双方喜欢”。

## 6. 现在 MATCH 不再靠最后一题碰运气

这是这次最重要的优化。

以前有个问题：很多5档题必须先 MATCH，但 MATCH 又主要靠第50题，可能整局都抽不到，于是5档几乎玩不到。

现在改成系统自己在合适的时候弹出一次秘密互选。

默认规则：

- 玩完至少9张有效题；
- 已经进入第3阶段；
- 系统已经至少给每个人安排过一次定向互动机会；就算有人选择跳过，也不影响其他人进入后面的秘密互选；

系统就会私下一个个问：

> “今晚到现在，你最想继续了解哪位异性？”

可以选一个人，也可以选“暂时没有”。

如果 A 选 D，同时 D 也选 A：

**❤️ A + D MATCH。**

如果只有 A 选 D：什么都不公开，系统算完就删掉。

## 7. 一局可以问几次秘密互选

不是只问一次，也不能老问。

- 第一次大约在第9张有效题之后。
- 再玩至少5张有效题，才可以再问一次。
- 常规最多3次。
- 游戏结束时一定还有一次最后复核。

所以即使第50题一直没抽到，也不会错过 MATCH。

### 如果有人一直跳过，会不会把全桌卡住？

**不会。**

系统只需要确认：

> “我已经给过你至少一次参与机会。”

你选择跳过完全没问题。跳过不会算成“完成互动”，系统之后也不会一直追着你出定向题；但它同样不会阻止其他人进入 H3、秘密互选和 MATCH。

简单说：**尊重你的跳过，也不让你的跳过变成全桌的惩罚。**

## 8. MATCH以后，5档要真的有机会出现

如果用户开放度选了5，某两个人刚 MATCH：

系统会在这两个人接下来的两次合适出场机会里，优先给至少一张5档题。

这样“互选成功 → 解锁专属内容”会真的发生，而不是只存在文档里。

### 后半场会不会还是老抽到不够热的题？

不会完全平均乱抽。除了“低档题到后期直接退出”以外，系统还有一层轻量偏好：

- H3：大约四分之三是3档，四分之一是2档；
- H4：以4档为主，少量3档；如果当前这对已经解锁5档，才允许混入5档；
- 真正的 MATCH 双人专属回合：以5档为主，4档辅助。

所以后半场会明显比前半场更有关系张力，不会因为均匀随机又退回普通聊天。

但仍然要照顾全桌公平，不能从此所有题都只给这一对。

## 9. MATCH不等于可以碰对方

MATCH只代表：

> “我们现在都愿意继续了解彼此。”

牵手、拥抱、靠近、坐到旁边、持续对视、拍照等，**每一次都重新问双方愿不愿意**。

一个人不愿意就直接跳过，不罚、不追问、不公布是谁拒绝。

## 10. 为什么“谁最可能”的结果不能直接把两个人推进5档

因为“全桌觉得你们有火花”只是别人的判断。

所以终局 Pair Vote 如果选出了 A+D，系统最多私下问两个人：

> “要不要多玩一张双人加赛？”

两个人都愿意，才多玩一张**最高4档、无身体接触**的双人题。

这不会自动创建 MATCH，更不会直接给牵手拥抱类内容。

## 11. 第50题不是必须全部跑一遍

每个游戏的50号题是“终局味道”的题，不是说一局必须把7张50号全部玩完。

最后阶段会提高它们的优先级；但真正的最终秘密互选由系统统一执行，所以不会因为随机没抽到某张终局题而漏掉收尾。

## 12. 小局为什么要给 MATCH 降一点权重

4～5人局可配的男女组合本来就少。

如果 MATCH 一出现就给超高优先级，很容易后半场全是同一对，其他人又开始看戏。

所以小局里 MATCH 仍然最强，但不会强到“锁死整桌”；而且 MATCH pair 也照样要遵守冷却轮次。

## 13. 这次还改了哪些题

- 大冒险1～2档换掉约一半“摆姿势 / 模仿”题，加入更像酒吧现场的轻互动。
- “坐到对方旁边”也改成需要对方当前同意，和靠近类规则统一。
- “谁最可能”4档从20张降到16张；4张较轻题移到3档，减少连续 Pair Vote 的重复感。
- 指人游戏4档从19张降到15张；4张较轻的选择移到3档。
- “我从来没有”高档重新统一成“我从来没有……”句式，不再变成普通问答。
- 真心话5档41～49直接在题面写明“两人轮流回答”。
- 二选一私密题不再偷偷参与 Compatibility 累积。
- 默契测试 #40 改回普通公开 Compatibility，不再误当成一次性互相同意。

## 14. “默契测试猜中了”会不会一直把这对人的分数越加越高？

不会。

前中段的默契题可以轻微帮助系统判断“这两个人可能值得再玩一次”，但加分很轻而且有上限。

一旦两个人已经 MATCH，41～49 这些5档默契题就只负责好玩和继续了解，**不再继续给后台配对分加码**。否则会出现“已经 MATCH → 越玩越加分 → 后面更只抽他们”的自我强化。

## 15. 扩圈模式也补完整了

40张扩圈题现在有独立元数据。

陌生人拒绝：立刻切回本桌替代版本，不再邀请第二次。

扩圈永远不参与 MATCH 和 Pair Score，也不索取联系方式、不要求身体接触或饮酒。

## 16. 最后只记6句话

1. 前半场先让所有人参与，后半场才往有火花的人靠。
2. 玩家选5档只是上限，不是马上玩5档。
3. 整桌只升到4档；5档属于具体两个人。
4. 别人觉得你们有戏不算，一个人单选也不算，双方秘密互选才叫 MATCH。
5. MATCH只代表愿意继续了解，不代表身体接触许可。
6. 软件只制造机会，最后怎么发展由玩家自己决定。
