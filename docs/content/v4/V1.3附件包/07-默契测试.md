# Party Night V2｜07 默契测试

> **核心职责：** 验证已经形成的连接：让特定两人通过同步选择、猜对方和私密共同选择，判断是否真的合拍。

## 执行规则

- 1～2档可用于普通系统配对；为了和“二选一”区分，低档也采用“先猜对方，再揭晓”的双人预测，而不是单纯比较两人的A/B答案。
- 3档优先给已互动过或 Compatibility Signal 较高的组合；4档优先给 Personal/Crowd/Shared 信号较强的组合；5档仅给 MATCH 对象。
- 默契测试测试的是“两个人之间”，不做全场投票，也不要求完成身体动作。
- 4档关系性答案默认私密；但 #40 是普通公开偏好比较题，按 Compatibility 处理，不创建一次性 Mutual Unlock。
- 若双方都愿意继续某个双人环节，只产生一次性 Mutual Unlock，不自动升级为 MATCH，也不持久保存谁单独选择了什么。
- 5档关系性答案只显示双方共同结果；任何一方改变主意都可以立即退出。
- Compatibility 口径分层：1～3档按“猜中对方”产生轻量路由证据，#40 按双方偏好是否一致；41～49 已经是 MATCH 专属题，**不再继续增加 Pair Engine 的 Compatibility 权重**，避免已 MATCH 的 pair 越滚越热。
