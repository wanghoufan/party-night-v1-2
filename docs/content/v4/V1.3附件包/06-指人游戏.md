# Party Night V2｜06 指人游戏

> **核心职责：** 公开个人选择：把“我会选谁”直接摆到桌面上，制造最清晰的 Personal Signal。

## 执行规则

- 与“谁最可能”不同：谁最可能是全桌判断，指人游戏是当前玩家自己的公开选择。
- 男女互动局中关系类题只允许指异性；被指的人默认无需回应，除非题面明确给出可选回应。
- 1～4档保持“公开个人选择”的玩法身份，但任何题都允许直接跳过，不能为了完成题面强迫制造虚假好感信号。
- 5档只保留秘密互选终局；公开单向高意向选择停在4档，避免与“5档=双向确认”的总规则冲突。
